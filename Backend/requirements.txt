# The strongest deterministic document reader, and the only one that can read a
# scanned page. A layout model finds a table as a region and TableFormer reads
# its cells, which is what a two-column journal page needs and what pdfplumber's
# text-layer heuristics cannot do; the same pass OCRs pages that have no text
# layer, so a scanned PDF arrives with words instead of being handed back to the
# reviewer as a chore.
#
# It costs about 215 MB of wheels (opencv, rapidocr, docling-parse, torchvision;
# torch is already here for the ranker) and downloads ~1 GB of its own models
# from Hugging Face the first time it runs.
#
# The tier stays lazy and guarded (Backend/docling_tables.py), so a build or a
# machine without it skips that rung instead of failing. EE_USE_DOCLING=0 turns
# it off.
#
# Not on Intel Macs: PyTorch stopped publishing x86_64 macOS wheels after 2.2.2,
# and docling's floor for torch and torchvision cannot be met with what is left,
# so asking for it there fails the whole install rather than that one feature.
# Those machines get every other rung of the ladder and no OCR.
