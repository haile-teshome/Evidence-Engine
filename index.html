Installing

macOS

  1. Open the downloaded .dmg and drag Evidence Engine onto Applications.
  2. Open your Applications folder, then control-click (or right-click) Evidence Engine and choose Open. Click Open again.
  3. If you are not offered an Open button, go to System Settings → Privacy & Security, scroll to the bottom, and click Open Anyway.

After that it opens normally from the Dock. Still refusing? In Terminal: xattr -dr com.apple.quarantine "/Applications/Evidence Engine.app"

Windows

  1. Run the downloaded Setup.exe.
  2. On the blue SmartScreen box, click More info, then Run anyway.
  3. Open Evidence Engine from the Start Menu.

It installs for your user only, so it never asks for an administrator password.

Linux

  1. Unzip the download anywhere.
  2. Run ./launch.sh from that folder.
