Architecture

Three processes cooperate on one machine, orchestrated by a single launcher.

app window frontend backend data store launcher local model cloud models
LayerStackResponsibility
FrontendReact 18, TypeScript, Vite, Tailwind, shadcn/uiAll UI, review state, IndexedDB session persistence, client-side PDF/DOCX/spreadsheet/reference parsing
BackendPython, FastAPI, uvicorn, LangChainRetrieval, model orchestration, screening, extraction, meta-analysis, and the projects/sessions store
StoreSQLite key-value tableSessions, reviewers, projects, papers, decisions, assignments, tags, calibration, risk-of-bias
ModelsOllama (local) or provider APIsQuery design, per-PICO screening, extraction, summarization, Q&A
LauncherNode script + native app wrapperBoots the stack, provisions Python + Ollama, opens the window, tears everything down on close

The frontend never imports backend code; it talks only through apiFetch() in src/app/lib/backendClient.ts, which issues /api/* calls that Vite proxies to localhost:8000. Two FastAPI routers are mounted under /api: the review pipeline (Backend/api.py) and the projects/sessions store (Backend/store.py).
