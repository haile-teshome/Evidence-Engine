Retrieval sources

Ten open-access connectors plus your own uploaded PDFs, defined in SERVICE_MAP (Backend/data_services.py). The canonical PubMed-style query is adapted to each engine's native syntax before fetching.

PubMedEurope PMCSemantic ScholarOpenAlexCrossRefarXivbioRxivmedRxivDOAJCORELocal PDFs

SourceApprox. indexNotes
OpenAlex~250M worksBroadest single source; no key needed
CORE~290M OA recordsBest-effort; a key is recommended
Semantic Scholar~220M papersRate-limited without a key
CrossRef~160M DOIsBibliographic, no full text
Europe PMC~44MSuperset of PubMed plus preprints; wide abstract coverage
PubMed / MEDLINE~38MRequires ENTREZ_EMAIL
DOAJ~10M OA articlesOpen-access journals
arXiv / bioRxiv / medRxiv~3M preprintsSTEM and biomedical preprints only
Two caveats. A single search returns a bounded slice, not the whole result set: max_per_source defaults to 10, with per-API page ceilings (OpenAlex ≤ 200, CrossRef ≤ 100, DOAJ ≤ 100). Deeper sweeps need pagination, which is on the roadmap. Institutional databases (Scopus, Embase, Web of Science) are intentionally excluded because they require paid access.
